# Audio Splitter App

A Flask and FFmpeg-based audio splitting web application.

## Features
- Split audio files by custom chunk length or equal parts.
- Powered by fmpeg and fprobe.
- Clean web interface with real-time processing and queue management.

## Setup & Run
1. Ensure FFmpeg is installed and added to PATH.
2. Install Python dependencies:
   \\\ash
   pip install flask
   \\\
3. Run the application:
   \\\ash
   python server.py
   \\\
